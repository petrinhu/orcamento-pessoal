PeuBud — Ajuda

Controle de parcelas do cartão de crédito

Começando

PeuBud exibe suas compras parceladas em uma tabela matricial:
linhas = compras · colunas = meses · células = valor da parcela naquele mês.

O mês atual é a primeira coluna visível. Role para a esquerda para ver meses passados, e para a direita para ver meses futuros.

Adicionar uma compra

Clique em + Nova compra. O diálogo tem três abas:

  • Valor por parcela — informe o valor de cada parcela e a quantidade.
  • Valor total — informe o total e a quantidade; o PeuBud calcula cada parcela. Use "já é a Xª parcela" se a compra já está em andamento.
  • Com juros — informe o total, a quantidade e a taxa mensal (ou o valor da parcela para calcular a taxa automaticamente via Newton-Raphson). O PeuBud calcula o CET e os juros totais.
A prévia ao lado direito atualiza em tempo real conforme você preenche.

Editar uma parcela

Clique duas vezes em qualquer célula de valor para editar. Um diálogo pergunta como recalcular as demais parcelas:

ModoO que faz
Só estaAltera apenas a parcela clicada
Redistribuir diferençaDistribui a diferença entre as demais parcelas não editadas
Igualar todasAplica o novo valor a todas as parcelas e recalcula o total
Recalcular jurosInfere a nova taxa de juros e redistribui as parcelas restantes

Excluir uma compra

Selecione a linha desejada e clique em Excluir. Todas as parcelas são removidas automaticamente (ON DELETE CASCADE).

Organizar as compras

  • Clique no cabeçalho de coluna — ordena por aquela coluna (1º clique: desc, 2º: asc).
  • Botão "Organizar por ▾" — define até 3 níveis de ordenação.

Cartões de crédito

Vá em Configurações → Cartões para cadastrar seus cartões (apelido). Ao adicionar uma compra, você pode associá-la a um cartão no campo "Cartão".

Tema (claro / escuro / auto)

Use os botões na barra superior direita: ☀ Claro, ◑ Auto, ☾ Escuro. O modo Auto segue as configurações do sistema operacional.

Importar dados

Use Arquivo → Importar de para carregar transações de outros apps ou do seu banco:

FormatoBancos que exportam
CSVTodos (Nubank, Itaú, Bradesco, BB, CEF, C6...)
OFX / QFXTodos os bancos brasileiros
XLSX / XLSBradesco, Itaú, BB, Santander
JSONNubank, MercadoPago, PicPay
TXT / CNABCEF, BB, Bradesco (banking corporativo)
Cada linha/transação importada vira uma compra com 1 parcela. Edite manualmente para converter em parcelamentos.

Exportar dados

Use Arquivo → Exportar para salvar sua planilha nos formatos:

  • PDF — relatório pronto para impressão
  • XLSX / XLS — abre no LibreOffice Calc e Microsoft Excel
  • CSV — separador ;, decimal , (padrão brasileiro)
  • OFX — importável em outros apps financeiros
  • JSON — formato estruturado para desenvolvedores
  • Markdown — tabela GFM para usar em documentos ou GitHub
  • HTML — página web com a tabela
  • TXT — texto simples com bordas ASCII

Salvar e abrir arquivos

  • Salvar (Ctrl+S) — salva a sessão atual.
  • Salvar como… — salva uma cópia no formato .pbd (criptografado AES-256-CBC).
  • Abrir… (Ctrl+O) — abre um arquivo .pbd existente.
